# 《基于位置的服务》团队课程设计 个人方案

作品名：GeoRelic

我在团队是前端开发。

因此， 我只用动Clients文件夹，其他的不要动（不然会git冲突）

选型：拟选用vue3前端框架

代码风格：你是一位资深的前端架构师，代码要满足简洁、清晰、可读易懂等规范与优点。注释不用多，但建议在关键的地方加上注释。



#### 教师提供的材料：

给定样区的POI 数据，文保景点的基本信息和经纬度坐标的数据集。我们需要在客户端（前端）做一个地图应用并展示poi，并添加后续功能。



#### 设计思路：

我用高德地图注册了一个apikey，现在要先能调用这个api，在前端能展示地图的底图（之后后端的成员会提供poi信息，不过现在他们还没做完）。

地图要可以放缩、拖动（就是基本功能）。
